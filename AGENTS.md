# Mandatory AI Contribution Policy

Before making commits, pull requests, reviews, issues, releases, or other attributable GitHub changes, read and obey [AI_ATTRIBUTION.md](AI_ATTRIBUTION.md).

Non-negotiable owner rules:
- AI-authored commits must name the exact model/version in commit trailers.
- AI-drafted PRs must name the drafting model and be reviewed at the final head SHA by a **different model** before merge.
- Both participating models must be identified in the PR.
- Never claim model participation that did not occur.

## Documentation Steward and ADR governance (proposed policy)

For material agent-orchestrated work, read [the Documentation Steward policy](docs/orchestration/DOCUMENTATION_STEWARD_POLICY.md) and maintain [the engagement record](docs/orchestration/ENGAGEMENTS.md). Delegate a suitable smaller model to draft ADRs, decisions, evidence links, outcomes and lessons when available; preserve existing ADR conventions. The orchestrator reviews accuracy and maintains technical authority; authorized humans accept consequential architectural decisions. Distinguish planned, implemented, validated, independently reviewed and accepted states. This proposal does not override existing AI attribution, product boundaries, security, permissions, or merge gates, and becomes active only following required review and authorized merge.
