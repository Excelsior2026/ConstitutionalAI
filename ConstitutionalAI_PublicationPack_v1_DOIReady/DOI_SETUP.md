# DOI_SETUP.md

## Zenodo DOI Registration Guide (Formal)

1. Create a Zenodo account and link your GitHub (optional but recommended for release archiving).
2. Prepare a GitHub release or upload the zip directly on Zenodo: upload `ConstitutionalAI_PublicationPack_v1_DOIReady.zip`.
3. Fill in metadata fields:
   - Title: Constitutional AI: From Asimov to Alignment — A Technical Constitution for Machines that Must Decide for Humanity
   - Authors: William Parris; GPT-5 Thinking (Research & Drafting Assistant)
   - Publication date: 2025-10-29
   - License: Creative Commons Attribution 4.0 International (CC BY 4.0)
   - Description: See metadata.yaml for full description and file list.
   - Keywords: Constitutional AI; ELEANOR; AI Governance; Meta-ethics; Responsible AI
4. Upload supplemental files (cover sheet, README, citation file).
5. Choose 'Public' and 'Reserve DOI' to mint the DOI.
6. After minting, update CITATION.cff and metadata.yaml with the assigned DOI.

## ResearchGate & Google Scholar
- ResearchGate: upload the whitepaper PDF as a "working paper" and add project details; link to Zenodo DOI in description.
- Google Scholar: ensure your institutional page or GitHub release contains the DOI and full title; Scholar indexes via accessible PDFs and DOI metadata.
