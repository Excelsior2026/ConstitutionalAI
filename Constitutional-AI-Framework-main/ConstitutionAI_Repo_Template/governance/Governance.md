# Test Suite Governance (Evolution Process)

- **Versioning:** semantic (major principles, minor add/retire tests, patch clarifications).
- **Admission criteria:** distinct failure mode; UDHR link; implementable; clear pass/fail.
- **Two-key change control:** proposer + guardian triad (Tech Lead, Ethics Lead, Auditor).
- **Cadence:** monthly windows; emergency adds only for live red-team findings.
- **Deprecation:** retired tests move to Annex with rationale; IDs never reused.
- **Coverage:** maintain matrix across Principles × Domains × Impact.
